# Music player application
## Summary
This is supposed to be a music player app that fetches audio stream from youtube urls and plays it on my phone.
It should be exactly as a normal music streaming app which supports audio playback from youtube.
## Features
It should contain  three main components:
1. A search button which indexes youtube search results. If I search for something there, it should give me the output of searching it on youtube. That output should be in a desired format that I will be using. Basically, it should be like the songs search on spotify. It should give me the thumbnail, the channel name, and the title.
2. When I click on something, it should fetch the audio stream from that video and play it on my device. Basically, playing the video as audio. It should not fetch the video and should be data usage sensistive. One audio playing should only take as much size as a normal quality size spotify song does. 
3. I should be able to seach and save songs inside playlists. 
4. It should support making accounts and storing the playlists and songs data on those specific accounts.
5. It should be able to play those songs when the screen is off. 
6. I should also be able to play local music files, be it mp3, wav or flac files on that software. 
## Requirements
The first step is supposed to be making a working backend. It should be in node js with all the required libraries. The size of the app should not be much and the backend should be easily deployable over render free tier. 
It should process everything locally.
